This section documents my comprehensive learning journey, research, and hands-on execution during the **12-week** **First Cloud AI Journey (FCAJ)** internship program. Throughout this program, I acquired in-depth knowledge of core **Amazon Web Services (AWS)** solutions, successfully executed complex hands-on laboratories, and developed robust competencies in architecting, automating, and operating secure cloud infrastructures adhering to the AWS Well-Architected Framework.

### 12-Week Curriculum Roadmap:

| Week | Duration | Core Theme | Primary AWS Services | Key Deliverables & Outcomes |
| :---: | :---: | :--- | :--- | :--- |
| **[Week 1](1.1-week1/)** | 01/10/2026 - 08/10/2026 | Cloud Fundamentals, IAM & Basic Compute | AWS IAM, AWS CLI, Amazon EC2, EBS | Secure root/IAM setup, credential management, EC2 provisioning |
| **[Week 2](1.2-week2/)** | 09/10/2026 - 15/10/2026 | Cloud Network Architecture | Amazon VPC, Subnets, Route Tables, IGW, NAT GW, SG, NACL | Multi-AZ isolated VPC with public/private tiering |
| **[Week 3](1.3-week3/)** | 16/10/2026 - 23/10/2026 | Object Storage & Content Delivery | Amazon S3, Route 53, CloudFront, ACM | High-speed global static website with custom domain and SSL |
| **[Week 4](1.4-week4/)** | 24/10/2026 - 31/10/2026 | Database Solutions & In-Memory Caching | Amazon RDS (Multi-AZ), DynamoDB, ElastiCache (Redis) | Relational database cluster, NoSQL table, and caching layer |
| **[Week 5](1.5-week5/)** | 01/11/2026 - 07/11/2026 | Monitoring, High Availability & Auto Scaling | Amazon CloudWatch, Alarms, SNS, ALB, Auto Scaling | Highly available self-healing compute tier with load balancing |
| **[Week 6](1.6-week6/)** | 08/11/2026 - 15/11/2026 | Serverless Computing & Event-Driven Architecture | AWS Lambda, API Gateway, Amazon SQS, Amazon SNS | Serverless microservices REST API with asynchronous messaging |
| **[Week 7](1.7-week7/)** | 16/11/2026 - 23/11/2026 | Infrastructure as Code (IaC) & Cloud Management | AWS CloudFormation, AWS CDK, Systems Manager (SSM) | Automated infrastructure provisioning and keyless instance management |

| **[Week 9](1.9-week9/)** | 01/12/2026 - 08/12/2026 | CI/CD Pipelines & Cloud DevOps | AWS CodeCommit, CodeBuild, CodeDeploy, CodePipeline | Automated end-to-end continuous integration and deployment pipeline |
| **[Week 10](1.10-week10/)** | 09/12/2026 - 16/12/2026 | Deep Defense Security & Governance | IAM Policies, KMS, Secrets Manager, WAF, GuardDuty, Security Hub | Defense-in-depth, data encryption at rest/in transit, threat detection |
